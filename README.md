# Vantage AI

Custom AI automation systems for dental practices, law firms, and med spas.

🔗 **Live site:** [realvantageai.co](https://realvantageai.co)

## About

Vantage AI builds and maintains custom AI-powered automation systems for small businesses, eliminating manual tasks and connecting existing tools into a single intelligent operation that runs 24/7 — without adding staff.

### What We Build

- **Background Automations** — Lead follow-up, appointment reminders, voicemail triage, review requests, and reporting
- **AI Chat Agents** — 24/7 chatbots that answer questions, book appointments, and qualify leads
- **Internal AI Assistants** — Private AI trained on business documents that staff can query instantly

## Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript
- **Animations:** Intersection Observer API, requestAnimationFrame particles
- **Fonts:** Inter via Google Fonts
- **Embeds:** Loom for case study videos
- **Hosting:** Netlify with continuous deployment from this repo
- **Domain:** Custom domain via Namecheap

## Features

- Conversion-focused single-page design
- Animated particle background on hero
- Smooth scroll-reveal animations
- Embedded Loom demo videos for live automation walkthroughs
- Fully responsive mobile-first layout
- Custom CTA flows to Google Calendar booking
